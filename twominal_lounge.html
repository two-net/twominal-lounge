Twominal Architecture & Stack Config

Pure static config file • No environment secrets • No Vault • PostgreSQL ORM Auto-Migrate

🐘 Database & Persistence

PostgreSQL instance with built-in ORM Auto-Migration on application boot. Strictly NO database partitioning. Single relational schema: Users, Lounges, ProximityNodes, Objects.

🔒 Zero-Secret Config File

Standardized lounge.config.json. No .env files, no dynamic secrets manager, and no Vault integration. Fully declarative and repeatable.

💼 SaaS Model

Software as a Service without subscription traps. Perpetual room licensing model (Single-space deployment, unlimited local peers, zero monthly recurring fees).

Auto-Migration Schema Definition Executed on Boot 
-- Auto-migrated schema: No Partitioning, Direct Foreign Keys
CREATE TABLE IF NOT EXISTS lounges (
    id VARCHAR(64) PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    max_capacity INT DEFAULT 50,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE TABLE IF NOT EXISTS lounge_occupants (
    id VARCHAR(64) PRIMARY KEY,
    lounge_id VARCHAR(64) REFERENCES lounges(id) ON DELETE CASCADE,
    display_name VARCHAR(120) NOT NULL,
    pos_x FLOAT NOT NULL DEFAULT 400.0,
    pos_y FLOAT NOT NULL DEFAULT 350.0,
    audio_active BOOLEAN DEFAULT FALSE,
    video_active BOOLEAN DEFAULT FALSE,
    current_zone VARCHAR(64) DEFAULT 'lobby',
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE TABLE IF NOT EXISTS whiteboard_notes (
    id VARCHAR(64) PRIMARY KEY,
    lounge_id VARCHAR(64) REFERENCES lounges(id) ON DELETE CASCADE,
    author_name VARCHAR(120) NOT NULL,
    content TEXT NOT NULL,
    color_class VARCHAR(64) NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
